# Resume Templates Collection

A collection of **4 professionally designed resume templates** built to help students, freshers, and professionals create a clear, attractive, and well-structured resume.

Whether you're applying for your first internship, looking for a job, or updating your professional profile, these templates give you a starting point to build a resume that represents you.

---

## ✦ Templates Included

This repository contains four different resume designs, each offering a distinct visual style and layout.

| Template | Description |
|---|---|
| **Template 01** | Clean and minimal design |
| **Template 02** | Modern professional layout |
| **Template 03** | Creative and visually appealing design |
| **Template 04** | Structured and elegant layout |

> Each template can be customised according to your personal information, education, skills, experience, and career goals.

---

## ✨ Features

- **4 Unique Designs** – Choose from four different resume layouts.
- **Easy Customisation** – Replace the sample information with your own details.
- **Professional Layouts** – Designed with readability and presentation in mind.
- **Beginner Friendly** – No advanced technical knowledge required.
- **Reusable** – Suitable for students, freshers, graduates, and working professionals.

## 🚀 Getting Started

Follow these simple steps to use the templates:

1. Clone this repository:

   ```bash
   git clone https://github.com/faizanshafi25/Resume_templates.git
   ```

2. Open the downloaded folder.
3. Browse the four available resume templates.
4. Open your preferred template's `index.html` file in a browser.
5. Replace the existing information with your own details.
6. Customise the design if required.
